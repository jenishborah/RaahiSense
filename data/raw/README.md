# Raw Dataset

This directory contains locally stored raw datasets used by RaahiSense.

The TIAND multimodal dataset is not included in this repository because of
dataset size and redistribution/licensing considerations.

Expected local structure:

data/raw/
└── TIAND_MULTIMODAL_DATASET/
    ├── Calibration_files/
    ├── CAMERA/
    ├── GNSS/
    ├── LIDAR/
    ├── RADAR/
    └── Synchronisation_timestamps/
